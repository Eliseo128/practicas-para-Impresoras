# Práctica: Identificación y revisión de consumibles de impresoras

**Asignatura:** Realiza mantenimiento preventivo y correctivo en impresoras
**Semestre:** 3.er semestre de preparatoria
**Duración:** 3 horas
**Nivel:** Básico–intermedio
**Modalidad:** Práctica supervisada

### Propósito de la actividad

El estudiante **identificará los principales consumibles y componentes de desgaste de una impresora**, determinará su función, revisará su estado físico y analizará cuándo deben sustituirse, utilizando como referencia la documentación técnica del fabricante.

### Aprendizaje esperado

Al finalizar la práctica, el estudiante será capaz de:

1. Identificar cartuchos de tinta y tóner.
2. Reconocer tambores, fusores, rodillos y cabezales.
3. Diferenciar consumibles de componentes de mantenimiento.
4. Revisar señales de desgaste o deterioro.
5. Consultar la documentación técnica correspondiente.
6. Determinar si un componente puede continuar en servicio o requiere sustitución.

---

## 1. Conceptos básicos

| Consumible/componente    | Función                                          | Equipo donde se encuentra principalmente | Señales de desgaste                                                   |
| ------------------------ | ------------------------------------------------ | ---------------------------------------- | --------------------------------------------------------------------- |
| **Cartucho de tinta**    | Contiene y suministra tinta                      | Impresoras de inyección de tinta         | Colores deficientes, líneas, manchas, aviso de tinta baja             |
| **Tóner**                | Contiene polvo de impresión                      | Impresoras láser                         | Impresión clara, manchas, zonas sin imprimir                          |
| **Tambor (Drum)**        | Transfiere la imagen electrofotográfica al papel | Impresoras láser                         | Líneas repetitivas, puntos, manchas o defectos constantes             |
| **Fusor**                | Fija el tóner al papel mediante calor y presión  | Impresoras láser                         | Tóner que se desprende, arrugas, atascos o problemas de fijación      |
| **Rodillos**             | Transportan y alimentan el papel                 | Impresoras de tinta y láser              | Atascos, alimentación múltiple o dificultad para tomar papel          |
| **Cabezal de impresión** | Deposita tinta sobre el papel                    | Inyección de tinta                       | Líneas, colores faltantes, impresión irregular o boquillas obstruidas |

> **Importante:** No todos estos elementos son necesariamente reemplazados con la misma frecuencia. La vida útil depende del modelo, volumen de impresión, tipo de papel, condiciones de operación y especificaciones del fabricante.

---

# 2. Materiales y recursos

### Materiales

* 1 impresora de inyección de tinta.
* 1 impresora láser, si está disponible.
* Cartuchos de tinta usados o nuevos.
* Cartucho de tóner.
* Tambor o unidad de imagen.
* Rodillos de alimentación, si están disponibles.
* Manuales o fichas técnicas de los equipos.
* Hojas de papel.
* Guantes de protección.
* Paño limpio y seco.
* Formato de registro de inspección.
* Computadora con acceso a la documentación técnica del fabricante.

### Seguridad

Antes de manipular cualquier impresora:

1. Apagar el equipo.
2. Desconectar el cable de alimentación cuando el procedimiento técnico lo indique.
3. Esperar a que las partes calientes se enfríen.
4. No tocar contactos eléctricos con las manos.
5. No tocar directamente la superficie fotosensible del tambor.
6. Evitar derramar tinta o dispersar tóner.
7. No abrir componentes que el fabricante indique que requieren servicio técnico especializado.
8. Seguir siempre el manual de servicio o mantenimiento correspondiente.

# 3. Desarrollo de la práctica — 3 horas

## A. Apertura — 30 minutos

### Actividad 1. Introducción del docente — 10 minutos

El docente explica:

* ¿Qué es un consumible?
* ¿Qué diferencia existe entre tinta y tóner?
* ¿Qué componentes tienen una vida útil determinada?
* ¿Por qué no debe sustituirse un componente solamente por su apariencia?
* ¿Qué importancia tiene consultar la documentación técnica?

### Actividad 2. Identificación inicial — 20 minutos

El docente muestra diferentes componentes y solicita a los estudiantes identificar:

**Cartucho → Tóner → Tambor → Fusor → Rodillo → Cabezal**

Los alumnos anotan para cada uno:

* Nombre.
* Función.
* Tipo de impresora.
* Posibles señales de desgaste.

---

# B. Desarrollo — 2 horas

## Actividad 3. Identificación física de componentes — 30 minutos

Organizados en equipos, los estudiantes observan los componentes disponibles.

Para cada elemento deberán registrar:

|   1 | Cartucho   |          |         |           |
|   2 | Tóner      |          |         |           |
|   3 | Tambor     |          |         |           |
|   4 | Fusor      |          |         |           |
|   5 | Rodillo    |          |         |           |
|   6 | Cabezal    |          |         |           |

**Producto:** Tabla de identificación.

---

## Actividad 4. Revisión visual de desgaste — 30 minutos

Los estudiantes realizan una inspección visual.

### Deben observar:

**Cartucho de tinta**

* Nivel de tinta.
* Fugas.
* Daños físicos.
* Contactos.
* Estado de los inyectores, cuando sea accesible.

**Tóner**

* Estado del cartucho.
* Fugas de polvo.
* Daños.
* Mensajes de tóner bajo.

**Tambor**

* Rayaduras.
* Manchas.
* Desgaste visible.
* Daños en la superficie.

**Rodillos**

* Desgaste.
* Grietas.
* Suciedad.
* Pérdida de adherencia.

**Cabezal**

* Obstrucciones.
* Defectos de impresión.
* Líneas o colores faltantes.

**Fusor**

* Evidencias de problemas de fijación.
* Atascos relacionados con la salida del papel.
* Deformaciones o daños visibles, **sin tocarlo si está caliente**.

---

## Actividad 5. Prueba de impresión — 20 minutos

Los estudiantes realizan una impresión de prueba.

Deben observar:

* Líneas verticales.
* Líneas horizontales.
* Manchas.
* Zonas sin impresión.
* Colores incorrectos.
* Texto borroso.
* Repetición de defectos.
* Tóner o tinta que no queda correctamente fijado.

### Registro

| Defecto observado | Posible componente relacionado | Evidencia |
| ----------------- | ------------------------------ | --------- |
| Líneas            | Cabezal/tambor                 |           |
| Manchas           | Cartucho/tóner/tambor          |           |
| Atasco            | Rodillos/fusor                 |           |
| Impresión clara   | Tinta/tóner                    |           |
| Tóner desprendido | Fusor                          |           |

> **Nota:** Una misma falla puede tener varias causas. El diagnóstico debe confirmarse mediante procedimientos y documentación del fabricante.

---

## Actividad 6. Consulta de documentación técnica — 20 minutos

Cada equipo consulta el manual, ficha técnica o documentación oficial correspondiente al modelo de impresora.

Buscar específicamente:

* Modelo del equipo.
* Número o código del consumible.
* Rendimiento aproximado.
* Indicador de vida útil.
* Procedimiento recomendado de sustitución.
* Mensajes de advertencia.
* Criterios de reemplazo.
* Precauciones de seguridad.

---

## Actividad 7. Decisión de sustitución — 20 minutos

Para cada componente, el estudiante debe determinar:

**CONTINUAR EN SERVICIO**

o

**REQUIERE SUSTITUCIÓN**

La decisión debe estar sustentada en:

1. Inspección visual.
2. Resultado de impresión.
3. Contador o indicador de vida útil, cuando exista.
4. Síntomas observados.
5. Documentación técnica.

### Ejemplo

**Situación:** La impresora presenta manchas repetitivas y la documentación indica que la unidad de imagen ha alcanzado su rendimiento especificado.

**Decisión:**
**Requiere sustitución del tambor/unidad de imagen**, siguiendo el procedimiento indicado por el fabricante.

---

# C. Cierre — 30 minutos

## Actividad 8. Comparación de resultados — 15 minutos

Cada equipo presenta un componente y explica:

* Qué componente identificó.
* Para qué sirve.
* Qué señales de desgaste encontró.
* Qué información encontró en la documentación.
* Si recomienda continuar utilizándolo o sustituirlo.
* Qué evidencia respalda su decisión.

## Actividad 9. Conclusiones — 15 minutos

Los estudiantes responden individualmente:

1. ¿Qué es un consumible?
2. ¿Cuál es la diferencia entre tinta y tóner?
3. ¿Qué función tiene el tambor?
4. ¿Qué función realiza el fusor?
5. ¿Qué función cumplen los rodillos?
6. ¿Qué función tiene el cabezal?
7. ¿Por qué es importante consultar la documentación técnica?
8. ¿Qué evidencias permiten determinar que un componente debe sustituirse?
9. ¿Por qué no se debe tocar directamente la superficie del tambor?
10. ¿Qué medidas de seguridad deben aplicarse durante la revisión?

# 5. Evaluación

| Evidencia             | Características                                                                 | Instrumento         |
| --------------------- | ------------------------------------------------------------------------------- | ------------------- |
| **Actividades 3 y 4** | Identifica correctamente los componentes y registra características de desgaste | Lista de cotejo     |
| **Actividad 5**       | Realiza e interpreta correctamente la prueba de impresión                       | Guía de observación |
| **Actividad 6**       | Consulta documentación técnica y localiza datos relevantes                      | Lista de cotejo     |
| **Actividad 7**       | Justifica técnicamente la decisión de continuar o sustituir                     | Rúbrica             |
| **Actividad 9**       | Explica conceptos, funciones y medidas de seguridad                             | Cuestionario        |

### Criterios de logro

**Excelente:** Identifica todos los componentes, interpreta correctamente las evidencias y fundamenta sus decisiones con documentación técnica.

**Satisfactorio:** Identifica la mayoría de los componentes y determina correctamente su estado con apoyo del docente.

**En proceso:** Identifica algunos componentes, pero requiere apoyo para interpretar el desgaste y determinar su sustitución.

**Requiere apoyo:** Presenta dificultades para identificar los componentes y relacionarlos con sus funciones.

### Resultado esperado

Al terminar las **3 horas**, el estudiante podrá **identificar cartuchos, tóner, tambores, fusores, rodillos y cabezales; reconocer evidencias de desgaste y determinar, con base en la documentación técnica del fabricante, cuándo un componente puede continuar en servicio o debe sustituirse**.
